Install the dashboard app

The dashboard can be installed like an app. It opens in its own window and keeps the latest data you viewed for use offline.

  • Computer (Chrome or Edge): click the install icon at the right of the address bar, or open the browser menu and choose “Install VBoS Statistics”.
  • Android: open the browser menu (⋮) and choose “Install app” or “Add to Home screen”.
  • iPhone or iPad (Safari): tap Share, then “Add to Home Screen”.
